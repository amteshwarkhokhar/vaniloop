Audit

Call 282: the buyer switches to a home dome camera at turn 7. The bot then asks drone specs at turns 12, 14 and 18. It asks the name 5 times, and the prompt allows 3. Fatal, first fault at turn 12.

Issue

"Specs from the wrong category after a product change" collects all calls like this. Causes seen in fewer than 3 calls do not rank.

Fix

The prompt resets ask counts on a product change (L83) but never says to drop the old specs. The edit adds that rule at that line.

Test

Replay from turn 12 with both prompts, several seeds each. Ship only if the new prompt fails less by more than the old prompt varies against itself, and no passing call breaks.

Fix and Test here describe the method. No live replay has run yet.

How the main decisions were made

Grade with rules, not with an LLM judge

Options: an LLM grades each parameter, or an LLM only labels turns and Python rules grade. Chosen: labels plus rules. Rules give exact counts (5 name asks vs a limit of 3) and every verdict points at turns. Source: ideation 01.

When in doubt, NeedsReview, never Pass

A wrong Pass hides a Fatal. Doubtful calls go to a human. Source: ideation 01.

Rank causes by the Wilson low bound, with a 3-call minimum

A cause seen in 2 calls must not outrank one seen in 40. The low bound penalises thin evidence. Source: ideation 02.

Ship a fix only if it beats the noise

A replay of the same prompt varies run to run. So we measure that variation first (old vs old) and require the fix to beat it, with no passing call broken. The idea comes from AgentCI and is rebuilt here. Source: ideation 04.

Use the real VANI prompt and its own limits

You supplied the prompt. Rules now use its limits (L69): product 4, quantity 3, each spec 2, name 3, city 3. Edits apply to real text. Source: 06 prompt map.

Changes made after the Codex reviews

Handoffs must confirm the product first (Codex found handoffs passing without one). Enrichment needs proof of the close. Replays use real seeds at temperature 0.7, because at temperature 0 every seed gives the same call and the noise floor reads zero.

Keep call data inside approved models

Call data goes to Claude, OpenAI/Codex and Gemini only. GLM and DeepSeek work on code only. Sarvam and TypeSafe get synthetic text until someone approves real text. Hackathon rule: customer data stays on premises.
